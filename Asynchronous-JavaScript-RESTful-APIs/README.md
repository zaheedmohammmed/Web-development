# Asynchronous JavaScript & RESTful APIs — Weather Dashboard

Live weather dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- City search using the Fetch API and `async`/`await`
- Error handling for location, network, and empty-result failures
- Dynamic rendering from nested geocoding and forecast JSON responses
- Live temperature, humidity, wind speed, feels-like temperature, and cloud cover

## Run
Open `index.html` in VS Code with Live Server. Internet access is required because the app calls Open-Meteo’s public geocoding and forecast APIs. No API key is required.
