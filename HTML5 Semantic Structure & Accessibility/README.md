# Accessible Portfolio

A responsive multi-page portfolio website built with semantic HTML and CSS. It is ready to upload directly to GitHub.

## Files

- `index.html` — home page
- `about.html` — profile and skills
- `projects.html` — sample project showcase
- `contact.html` — contact form layout
- `style.css` — shared responsive styles

## Use it

1. Extract the ZIP file.
2. Upload these files to a new GitHub repository.
3. Replace “Alex Morgan” and `hello@example.com` with your own details.
4. Open `index.html` to preview the site.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and the `/ (root)` folder.

## Accessibility features

- Semantic landmarks and heading hierarchy
- Skip-to-content link
- Keyboard-visible focus styles
- Responsive layout and readable contrast
- Clearly associated form labels

The contact form is a visual template; connect it to a form service or server endpoint to receive messages.
