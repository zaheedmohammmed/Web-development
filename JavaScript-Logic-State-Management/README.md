# JavaScript Logic & State Management — To-Do List

A client-side To-Do List built with vanilla HTML, CSS, and JavaScript.

## Features

- Create, read, edit, and delete tasks
- Mark tasks complete or active
- Filter tasks by All, Active, or Completed
- Clear all completed tasks
- Automatically save tasks with `window.localStorage`
- Use event delegation for task actions
- Responsive, accessible interface

## Run it

Open `index.html` in a browser, or use the Live Server extension in VS Code. No installation or packages are required.

## Project files

- `index.html` — app structure
- `style.css` — responsive styling
- `script.js` — state, local storage, DOM rendering, and event handling
