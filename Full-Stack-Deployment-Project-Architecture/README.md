# Full-Stack Deployment & Project Architecture — Luma Market

A production-ready static e-commerce catalog prototype. It uses modular client-side rendering, hash-based routing, responsive layouts, and persistent cart state.

## Features
- Hash routing: Home, Shop, and Cart
- Filterable product catalog
- Add, remove, and update cart quantities
- Cart persistence with `localStorage`
- Responsive mobile-first design
- Lightweight assets: CSS illustration and emoji product placeholders mean no large image downloads

## Deploy
1. Upload these files to GitHub.
2. Import the repository into Netlify or Vercel.
3. Use the default static-site settings; no build command is needed.
4. Deploy to receive your public URL.

The public URL must be generated from your own deployment account, so it cannot be created inside this ZIP.
